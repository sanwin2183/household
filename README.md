# Household — Personal Finance Ledger

Personal finance tracker shared between you and your wife. THB currency. Six categories.

## Setup (one-time)

### 1. Firebase
- Create new Firebase project
- Enable Firestore (asia-southeast1)
- Set rules to `allow read, write: if true;`
- Copy config into `src/firebase.js`

### 2. GitHub
- Create repo named `household`
- Push this code
- Settings → Pages → Source: GitHub Actions

### 3. Live URL
`https://YOUR-USERNAME.github.io/household/`

## Default passcode
`household2026` — change in Settings on first login.
